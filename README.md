# iXPDF - Private PDF Tools

> 浏览器本地运行的 PDF 工具（压缩 / 合并 / 拆分 / 转换）

Free, fast, private PDF tools that run entirely in your browser - compress, merge, split, convert and edit locally

## Features

- Compress PDFs without losing readable quality
- Merge, split and reorder pages
- Convert between PDF and common image formats
- No upload - files stay on your own device
- Works offline once the page is loaded

## Tech Stack

`PDF` `Privacy` `WebAssembly` `Browser-based` `Document Tools`
